# Changelog

## [0.2.0] - 2026-10-02

### Added

- Self-contained Windows deployment
- Windows installer using Inno Setup
- First-run setup wizard
- SQLite local standalone database mode
- Existing MySQL database mode
- MySQL connection testing during setup
- Secure MySQL password storage using Windows DPAPI
- Automatic local API startup and shutdown
- API health detection
- Configurable API endpoint
- Optional database preservation during uninstall
